# Java Beginner Projects
A collection of beginner-friendly Java projects and practice programs created while learning Java programming fundamentals through the Pro Code YouTube course.

## About
This repository documents my progress while learning Java and practicing programming fundamentals through small projects and exercises.

The projects cover topics such as:
- Variables and data types
- User input with `Scanner`
- Arithmetic operations
- Conditional statements
- Logical operators
- `switch` statements
- Ternary operator
- String methods
- Mathematical operations
- Random values
- Basic problem-solving

## Projects
### 1. Calculator
A simple calculator that performs basic arithmetic operations using conditional statements.
**Concepts:** `Scanner`, variables, arithmetic operators, `if-else`.
---
### 2. Calculator Switch
A calculator implemented using the `switch` statement. It supports addition, subtraction, multiplication, division, and exponentiation.
**Concepts:** `switch`, arithmetic operators, `Math.pow()`.
---
### 3. Shopping Cart
A simple shopping cart program that asks the user for an item, its price, and the quantity, then calculates the total cost.
**Concepts:** `Scanner`, variables, arithmetic operations, user input.
---
### 4. Mad Libs Game
A simple interactive word game that collects input from the user and uses it to create a short story.
**Concepts:** `Scanner`, `String`, user input, string concatenation.
---
### 5. Compound Interest Calculator
A program that calculates compound interest using the principal amount, interest rate, number of periods, and time.
**Concepts:** `Scanner`, variables, mathematical formulas, `Math.pow()`.
---
### 6. Temperature Converter
A program that converts a temperature between Celsius and Fahrenheit based on the selected unit.
**Concepts:** `Scanner`, `String`, conditional logic, ternary operator.
---
### 7. Username Validator
A simple program that checks whether a username meets specific requirements, including its length and whether it contains spaces or underscores.
**Concepts:** `String` methods, `if-else`, logical operators.
---
### 8. Email Parser
A program that extracts the username and domain from an email address entered by the user.
**Concepts:** `String`, `substring()`, `indexOf()`, `contains()`.
---
### 9. Enhanced Switches
A program that determines whether a given day is a weekday or a weekend using the enhanced `switch` statement.
**Concepts:** Enhanced `switch`, `String`, user input.
---
### 10. Nested If Example
A practice program demonstrating conditional logic using `if`, `else if`, and `else`.
**Concepts:** Conditional statements, boolean values, logical conditions.
---
## Practice Programs

### Logical Operators
A practice program demonstrating the logical operators `&&`, `||`, and `!`.

### Random Demo
A simple demonstration of Java's `Random` class for generating random numbers and boolean values.

### Mathematics
A practice program demonstrating commonly used methods and constants from Java's `Math` class.
**Examples:** `Math.PI`, `Math.E`, `Math.pow()`, `Math.abs()`, `Math.sqrt()`, `Math.floor()`, `Math.ceil()`, `Math.max()`, and `Math.min()`.
