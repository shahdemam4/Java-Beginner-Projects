# Java Beginner Projects

A collection of beginner-friendly Java projects created to practice programming fundamentals, problem-solving, and core Java concepts.

## Projects

### 1. Calculator

A console-based calculator that performs basic arithmetic operations.

**Concepts:**
Variables, user input, arithmetic operators, conditional statements.

---

### 2. Shopping Cart

A simple shopping cart application that works with products, prices, quantities, and the total cost.

**Concepts:**
Variables, user input, arithmetic operations, conditional statements, basic program logic.

---

### 3. Mad Libs Game

An interactive console game that collects words from the user and uses them to generate a custom story.

**Concepts:**
String manipulation, user input, variables, program flow.

---

### 4. Discount Calculator

Calculates the final price of a product after applying a specified discount percentage.

**Concepts:**
User input, variables, arithmetic operations, percentages.

---

### 5. Compound Interest Calculator

Calculates compound interest based on the principal amount, interest rate, and number of periods.

**Concepts:**
User input, arithmetic operations, `Math.pow()`, variables, mathematical formulas.

---

### 6. Student Information

A console program that collects basic information from the user and displays the entered data.

**Concepts:**
`Scanner`, variables, data types, boolean values, `if-else` statements.

---

### 7. Hypotenuse & Circle Calculator

A collection of basic geometric calculations implemented using Java.

**Concepts:**
Arithmetic operations, `Math.sqrt()`, `Math.pow()`, variables, user input.

---

### 8. Java Math Practice

A practice program demonstrating commonly used constants and methods from Java's `Math` class.

**Concepts:**

* `Math.PI`
* `Math.E`
* `Math.pow()`
* `Math.abs()`
* `Math.sqrt()`
* `Math.round()`
* `Math.floor()`
* `Math.ceil()`
* `Math.max()`
* `Math.min()`

---

### 9. Area Calculator

A simple program that calculates the area of a rectangle using user-provided length and width.

**Concepts:**
User input, variables, arithmetic operations, basic mathematical formulas.

---
